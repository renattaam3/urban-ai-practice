# Оценка размещения школ

Интерактивное Streamlit-приложение для оценки обеспеченности населения школьными местами и подбора кварталов под новые школы. Расчёт выполнен по методике BlocksNet из ноутбука `examples/karabash_study.ipynb` и воспроизводит исходный файл `school_provision.csv`.

## Что умеет приложение

- Показывает исходную обеспеченность школьными местами.
- Позволяет выбрать квартал на карте или в списке и добавить одну или несколько новых школ с заданной вместимостью.
- Пересчитывает сценарий: новая школа увеличивает вместимость своего квартала и распределяет места среди жителей соседних кварталов в пределах времени доступности.
- Автоматически перебирает все кварталы для одной новой школы и показывает таблицу всех проверенных вариантов.
- Показывает карту в режимах «Исходное», «Сценарий» и «Изменение».
- Показывает карточку выбранного квартала, итоговые показатели и таблицы сравнения.
- Экспортирует результаты в CSV и сбрасывает сценарий.
- Не изменяет исходные файлы в папке `results`.

## Быстрый запуск

В репозитории уже есть виртуальное окружение `.venv` с установленными зависимостями. Из корня репозитория (`python-package-boilerplate`) выполните:

```powershell
.venv\Scripts\streamlit.exe run school-placement\app.py
```

Либо из папки `school-placement`:

```powershell
..\.venv\Scripts\streamlit.exe run app.py
```

После запуска откройте адрес, который выведет Streamlit, обычно:

```text
http://localhost:8501
```

### Установка с нуля

```powershell
cd school-placement
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

Требуется Python 3.10+.

## Исходные данные

По умолчанию приложение ищет данные в папке:

```text
../examples/data/suzdal/results
```

относительно `school-placement`, то есть в `python-package-boilerplate/examples/data/suzdal/results`.

Используются файлы:

- `blocks_land_use.geojson` — геометрия кварталов.
- `density_indicators.csv` — плотностные показатели кварталов.
- `school_provision.csv` — текущая вместимость школ и исходная обеспеченность.
- `accessibility_matrix.csv` — матрица времени в пути между кварталами.
- `blocks_results.csv` — население кварталов (в текущем наборе именно здесь находится колонка `population`).
- `raw/schools.geojson` — точки существующих школ для карты, если файл доступен.

В текущем наборе `density_indicators.csv` не содержит колонку `population`, поэтому население берётся из `blocks_results.csv`. Если в другом наборе данных колонка `population` есть в `density_indicators.csv`, приложение автоматически использует её. Источник населения отображается в интерфейсе.

Чтобы указать другую папку с результатами, задайте переменную окружения:

```powershell
$env:SCHOOL_RESULTS_DIR = "C:\path\to\results"
.venv\Scripts\streamlit.exe run school-placement\app.py
```

## Методика

Параметры взяты из ноутбука `karabash_study.ipynb`:

- нормативный спрос — `120` школьных мест на `1000` жителей;
- время доступности — `15` минут;
- скорость пешего передвижения — `5` км/ч (матрица уже рассчитана);
- расчёт обеспеченности — `blocksnet.analysis.provision.competitive_provision` с самопокрытием квартала и `max_depth=1`.

Спрос квартала:

```text
спрос = ceil(население / 1000 × 120)
```

Дефицит — это сумма `demand_left`, то есть спрос, который не удалось покрыть местами в пределах 15 минут после конкурентного распределения.

Исходный расчёт проверяется при запуске: приложение сравнивает все 10 показателей `school_provision.csv` для 89 кварталов с расчётом BlocksNet. В текущем наборе максимальное расхождение равно `0`.

### Автоподбор

Для каждой вместимости новой школы приложение независимо проверяет все 299 кварталов:

1. добавляет вместимость в очередной квартал;
2. решает ту же LP-задачу конкурентного распределения мест (решатель HiGHS);
3. считает суммарный дефицит после размещения;
4. выбирает кварталы с максимальным сокращением дефицита.

Одинаковые лучшие результаты не отбрасываются: в таблице и сообщении показываются все кварталы с максимальным сокращением. Лучший вариант дополнительно пересчитывается через BlocksNet, чтобы карточка и карта использовали тот же расчёт, что и исходная обеспеченность.

## Как пользоваться

1. Нажмите на квартал на карте или выберите его ID в панели слева.
2. Введите вместимость школы (положительное целое число) и нажмите «Добавить школу».
3. Можно добавить несколько школ, в том числе в разные кварталы.
4. Нажмите «Рассчитать сценарий».
5. Переключайте режимы карты: «Исходное», «Сценарий», «Изменение».
6. Для автоматического подбора задайте вместимость новой школы (по умолчанию 600) и нажмите «Разместить автоматически».
7. Вкладка «Автоподбор» показывает все проверенные кварталы и позволяет применить любой из лучших вариантов.
8. Кнопки экспорта в панели слева и во вкладках сохраняют CSV.
9. Кнопка «Сбросить сценарий» возвращает исходные показатели.

## Проверки

- Вместимость принимается только как положительное целое число; число мест настраивается через целочисленный ввод.
- Сценарий рассчитывается в памяти на копии исходных данных. Файлы в `results` не перезаписываются.
- При запуске выполняется сверка с `school_provision.csv`.
- Автоподбор проверяет каждый из 299 кварталов.
- Все кварталы с одинаковым лучшим результатом выводятся в таблице и списке лучших.

## Экспорт

Доступны CSV-файлы:

- `scenario_comparison.csv` — сравнение всех кварталов: вместимость, дефицит, обеспеченность до и после;
- `scenario_summary.csv` — итоговая сводка сценария;
- `scenario_schools.csv` — список новых школ;
- `search_results.csv` — все проверенные варианты автоподбора.

CSV сохраняется в UTF-8 с BOM, чтобы корректно открываться в Excel.

## Возможные проблемы

- **Не найдена папка с данными.** Проверьте, что `examples/data/suzdal/results` существует, или задайте `SCHOOL_RESULTS_DIR`.
- **Порт 8501 занят.** Запустите с другим портом:

  ```powershell
  .venv\Scripts\streamlit.exe run school-placement\app.py --server.port 8502
  ```

- **Долгий автоподбор.** Проверяются все 299 кварталов; на текущем наборе это занимает несколько секунд. В интерфейсе отображается прогресс.
